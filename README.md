# Professional Android Cricket Scorer App

## 1. Project Overview
A feature-rich Mobile Application Development (MAD) lab project built using **Kotlin** and **Jetpack Compose**. This application provides a seamless, real-time digital scoring experience for cricket matches, complete with automated rule enforcement, individual player statistics, and match setup configurations.

## 2. Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Declarative UI)
* **IDE:** Android Studio
* **Version Control:** Git & GitHub

## 3. Core Features Implemented
* **Animated Splash Screen:** Professional entry screen welcoming users to the app.
* **Match Setup Screen:** Allows users to configure match details including Venue, Team Names, Total Overs, and Opening Players.
* **Live Scoring Engine:** Real-time tracking of total score, wickets, overs, current run rate (CRR), and extras (wides/no-balls).
* **Player Statistics:** Live batting stats (runs scored, balls faced) and bowling stats (overs bowled, runs conceded, wickets taken).
* **Automated Rule Enforcement:** Automatic strike rotation on odd runs and over completions, along with manual strike-change options.
* **Interactive Dialogs:** Popups for wicket handling, over completion, and player name editing.

## 4. How to Run the App
1. Clone the repository: `git clone https://github.com/Nabeel1616/CricketScoreApp.git`
2. Open **Android Studio** and select *Open an Existing Project*.
3. Wait for Gradle sync to complete.
4. Run the app on an Android Emulator or physical device running API level 24 or higher.
